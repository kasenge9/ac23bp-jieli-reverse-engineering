# Repository Structure

This repository contains the research white paper and supporting documentation for the reverse-engineering investigation of the AC23BP Jieli Bluetooth speaker module.

## Directories

- `docs/` — research notes, investigation logs, and white-paper source material
- `notes/` — raw observation notes and analysis findings
- `images/` — board photographs, close-ups, and trace documentation
- `firmware/` — firmware-related notes, scripts, and extracted artifacts when available
- `schematics/` — draft schematic notes and board trace documentation

## Primary Document

- `README.md` — main white paper and project overview

## Goal

The goal of this repository is to document a disciplined reverse-engineering effort from hardware identification to firmware and Bluetooth analysis, while preserving a clear distinction between observation, inference, and experimental modification.
