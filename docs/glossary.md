# Reverse Engineering Glossary

## A

### ADC
Analog-to-Digital Converter. Converts an analog signal into digital data.

### Amp
Abbreviation for amplifier. Also refers to current measurement unit (ampere).

## B

### Bootloader
A small program responsible for initializing hardware and/or loading application firmware.

### Bluetooth BR/EDR
Bluetooth Basic Rate/Enhanced Data Rate. The classic Bluetooth standard for longer-range connections.

### BLE
Bluetooth Low Energy. Designed for low-power wireless communication.

## C

### Continuity Test
An ohm-meter measurement confirming electrical connection between two points. Typically shows beep or very low resistance (< 1 Ω).

## D

### DAC
Digital-to-Analog Converter. Converts digital audio data into an analog signal.

### Debug Port
An electrical interface (JTAG, SWD, UART) used for testing and debugging hardware and firmware.

### DSP
Digital Signal Processor. A processor optimized for operations such as audio and signal processing.

## E

### EEPROM
Electrically Erasable Programmable Read-Only Memory. Nonvolatile memory where small amounts of configuration data are typically stored.

## F

### Firmware
Software stored in a device that controls its hardware and main operations.

### Flash
Nonvolatile memory technology commonly used for program and data storage in embedded systems.

## G

### GPIO
General-Purpose Input/Output. Configurable digital pins used for control and communication.

## I

### I2C
Inter-Integrated Circuit. A serial communication protocol commonly used for configuration and sensor interfaces.

### I2S
Inter-IC Sound. A digital audio interface standard.

### IC
Integrated Circuit. A chip containing transistors and other components manufactured as a single device.

## J

### JTAG
Joint Test Action Group. A debugging interface standard often used on embedded systems.

## M

### MAC Address
Media Access Control address. A unique identifier assigned to network devices. For Bluetooth, it's a 48-bit address (e.g., 93:91:63:79:F6:A9).

## O

### Ohm
Unit of electrical resistance. Represented by Ω.

## P

### PCB
Printed Circuit Board. The board containing mounted components connected by copper traces.

### Profile
In Bluetooth, a standardized set of specifications and behaviors (e.g., Audio Profile).

## R

### RF
Radio Frequency. The portion of the circuit associated with wireless transmission and reception.

### ROM
Read-Only Memory. Memory that cannot be modified after manufacturing, typically used for bootloaders.

## S

### SoC
System-on-Chip. An integrated IC containing multiple functions that might otherwise require several separate chips.

### SWD
Serial Wire Debug. A debugging interface protocol used on ARM Cortex processors.

## T

### Test Point
A PCB pad provided for manufacturing, testing, debugging, or programming.

### Trace
A copper line on a PCB connecting two components.

## U

### UART
Universal Asynchronous Receiver/Transmitter. A common serial communication interface.

### USB
Universal Serial Bus. A digital interface used for power, data, or both.

## V

### Voltage
Electric potential difference, measured in volts (V).

### Volt
The SI unit of voltage.
