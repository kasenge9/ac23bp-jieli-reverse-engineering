# Images and Board Trace Documentation

This directory is intended to hold all visual and trace documentation produced during the hardware analysis. It should be organized as follows:

- `images/front/` — front-side board photographs
- `images/back/` — rear-side board photographs
- `images/closeups/` — IC, crystal, antenna, pad, and connector close-ups
- `images/annotated/` — annotated images showing important nets, traces, and suspected signal groups
- `schematics/` — draft board-level schematics or netlists as they are developed
- `traces/` — trace maps, continuity logs, and route notes
- `measurements/` — oscilloscope and logic analyzer captures, if available

## Documentation Expectations

For each image or trace document:

- include a date
- note the view (front/back/close-up)
- identify the component or net under inspection
- record any measurement or continuity result
- classify the result as observed fact, inferred relationship, or unconfirmed hypothesis

This structure helps maintain a disciplined evidence trail while the board is being reverse engineered.
